#+title: YPCB DDR3 Parameter Limits

* Assumptions

This note compares the current LLM2FPGA/YPCB UberDDR3 configuration against the
theoretical limits implied by the YPCB-00338-1P1 board and its Micron
=MT41K256M8DA-125:K= DDR3L SDRAM.

- Current profile: one byte lane, =DDR3_CLK_PERIOD=3750 ps, =CONTROLLER_CLK_PERIOD=15000 ps.
- The Micron =-125= speed grade supports DDR3-1600, i.e. 800 MHz CK and 1600 MT/s.
- =MT41K256M8= is a 2Gb x8 device with 15 row bits, 10 column bits, and 3 bank bits.
- The local YPCB top exposes 64 data pins, so UberDDR3 can theoretically use 8 byte lanes in this design.
- The board article describes each memory group as 9 x8 chips, a raw 72-bit ECC channel. This local design currently exposes 64 data bits, not the ECC byte as a separate ninth lane.

Current one-byte-lane theoretical peak:

#+begin_example
266.667 MHz * 2 * 8 bits = 4.267 Gbit/s = 533.3 MB/s
#+end_example

Maximum for one =MT41K256M8DA-125:K= x8 chip:

#+begin_example
800 MHz * 2 * 8 bits = 12.8 Gbit/s = 1.6 GB/s
#+end_example

Maximum for the 64-bit data bus exposed by this local YPCB design:

#+begin_example
800 MHz * 2 * 64 bits = 102.4 Gbit/s = 12.8 GB/s
#+end_example
